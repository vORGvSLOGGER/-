# 🍬⚔️ حرب الحلويات — Candy War

لعبة Match-3 قتالية: ادمج الحلويات لتضرب خصمك وتدمّر طبقات صحته الثلاث قبل ما يدمّرك!

## 🚀 التشغيل

```bash
npm install
npm start
```

ثم افتح المتصفح على: **http://localhost:3000**

> للأونلاين بين جهازين على نفس الشبكة: افتح `http://<عنوان-جهازك>:3000` من الجهاز الثاني.

## 🎮 نظام اللعب

- لوحة **8×8** — اسحب حلوى لتبديلها مع المجاورة
- **دمج ٣** → ٣ نقاط ضرر للخصم → **ينتقل الدور**
- **دمج ٤ أو أكثر** → ضرر بعدد الحلويات → **تكمل دورك!**
- التساقطات المتسلسلة (كومبو) تضيف ضرراً إضافياً 🔥
- **المؤقت ٣٠ ثانية** يمشي طول دورك — خلص وقتك؟ الدور للي بعدك!
- **الصحة ٣ طبقات**: 🟢 أخضر ٤٠ + 🟡 أصفر ٤٠ + 🔴 أحمر ٤٠ = ١٢٠ نقطة
- الحلويات تطير بأنيميشن وتنفجر على شريط صحة الخصم 💥
- آخر لاعب صامد يفوز 🏆

## 🕹️ أنماط اللعب

| النمط | الوصف |
|---|---|
| 🌐 **أونلاين** | رومات عامة أو خاصة بكود ٦ أحرف — أنشئ رومك واختر الطور |
| 🤖 **ضد الكمبيوتر** | ٣ صعوبات: سهل 😊 / متوسط 😐 / صعب 😈 |
| 👨‍👩‍👧 **محلي** | ٢ - ٤ لاعبين بالتناوب على نفس الجهاز |

## ⚔️ الأطوار

- **⚔️ الكلاسيكي**: ٣٠ ثانية للدور • ١٢٠ صحة
- **⚡ البرق**: ١٥ ثانية فقط • ٩٠ صحة — سرعة جنونية
- **💀 الموت المفاجئ**: طبقة واحدة ٤٠ • دمج ٥+ بضرر مضاعف

## 🛒 المتجر والعملات

- اكسب 🪙 من اللعب: فوز أونلاين ١٠٠ • ضد الكمبيوتر ٢٠/٤٠/٧٠ حسب الصعوبة • محلي ٣٠ • مشاركة ١٠
- **معززات**: 💣 قنبلة 3×3 • ⏰ +١٠ ثواني • 🔀 خلط اللوحة • 🛡️ درع يمتص ١٠ ضرر
- **ثيمات حلويات**: فواكه 🍓 • جواهر 💎 • حيوانات 🐱
- **أفاتارات مميزة**: 👑 🐉 🦄 🤖 😈 🥷

## 👥 الأصدقاء والشات

أضف أصدقاءك بكودهم المكون من ٦ أحرف (يظهر تحت اسمك)، وراسلهم بشات مباشر.

## 🌍 النشر

### GitHub Pages (نسخة بدون أونلاين)
1. اجعل المستودع **Public** من Settings → General → Danger Zone → Change visibility
2. فعّل Pages: Settings → Pages → Source: **GitHub Actions**
3. أعد تشغيل الـ workflow من تبويب Actions — الدومين: `https://vorgvslogger.github.io/-/`

### Render.com (اللعبة كاملة مع الأونلاين — مجاني)
1. سجّل في [render.com](https://render.com) بحساب GitHub
2. New + → **Web Service** → اختر مستودع اللعبة
3. اضغط Deploy (الإعدادات تنقرأ تلقائياً من `render.yaml`)
4. الدومين يطلع لك بشكل: `https://candy-war.onrender.com`

## 🛠️ التقنية

- **Frontend**: HTML + CSS + Vanilla JavaScript (بدون أي frameworks)
- **Backend**: Node.js + Express + Socket.IO
- لوحات الأونلاين متزامنة ١٠٠٪ عبر بذرة عشوائية مشتركة (deterministic seed)
- المؤثرات الصوتية مولّدة بـ Web Audio API بدون ملفات
